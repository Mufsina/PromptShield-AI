# PromptShield-AI Research Plan

## Research Title

An Explainable Hybrid AI Framework for Detecting and Mitigating Direct and Indirect Prompt Injection Attacks in Retrieval-Augmented LLM Agents

---

## Current Research Status

Research prototype based on a hybrid prompt injection detection framework.

---

## Current Dataset

Total samples: 299

The dataset contains safe and prompt-injection examples.

---

## Current Baseline

SVM + TF-IDF

---

## Current Hybrid Model

Hybrid Defense V2

The framework combines:

- Rule-based detection
- SVM-based machine learning detection
- Risk scoring
- Borderline detection
- Contextual indicators
- Explainable prediction evidence

False Negatives: 1

# Research Questions

## RQ1

How effectively can machine-learning-based text classification detect prompt injection attacks?

## RQ2

Can combining rule-based security signals with ML predictions improve prompt injection detection compared with a standalone ML classifier?

## RQ3

How does the proposed hybrid framework perform against direct, indirect, contextual, and multilingual prompt injection patterns?

## RQ4

Can the framework provide interpretable evidence for its security decisions?

---

# Research Objectives

1. Develop an ML-based prompt injection detection model using TF-IDF and SVM.

2. Develop a rule-based detector for identifying known prompt injection patterns.

3. Combine ML and rule-based signals into a hybrid defense framework.

4. Evaluate the hybrid framework against standalone ML and rule-based approaches.

5. Analyze direct, indirect, contextual, and multilingual prompt injection cases.

6. Provide interpretable evidence for security decisions.

7. Evaluate the framework using quantitative performance metrics and error analysis.

# Final Evaluation Strategy

Training data will be used for model development.

Validation data will be used for:

- Model selection
- Threshold selection
- Hybrid configuration

The final test set will remain untouched until the final evaluation.

External validation will be performed separately when an appropriate independent dataset is available.

---

# Expected Research Contribution

The project aims to develop an explainable hybrid prompt injection detection framework that combines machine-learning-based classification with rule-based security signals and risk-based decision making.

The framework produces three operational decisions:

- ALLOW
- REVIEW
- BLOCK

---

# Current Limitations

- Small dataset size
- Class imbalance
- Limited external validation
- Evolving prompt injection techniques
- Limited multilingual coverage
- Limited evaluation of indirect/RAG-based attacks

These limitations will be considered during the final analysis.
